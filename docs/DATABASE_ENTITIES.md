# NEXUS Database Schema Specification

This document details the relational database schema, primary entities, indexes, and constraints for the **NEXUS Agentic AI Operating System** using PostgreSQL (with `pgvector`) or SQLite with WAL mode.

---

## 1. Entity Relationship Diagram (Conceptual)

```
┌──────────────────┐       1:N       ┌──────────────────┐
│     sessions     ├────────────────►│    task_dags     │
└────────┬─────────┘                 └────────┬─────────┘
         │ 1:N                                │ 1:N
         ├──────────────────┐                 ▼
         │                  │        ┌──────────────────┐
         ▼                  ▼        │    dag_nodes     │
┌──────────────────┐ ┌─────────────┐ └────────┬─────────┘
│    audit_logs    │ │  memories   │          │ 1:1
└────────┬─────────┘ └─────────────┘          ▼
         │ 1:1                       ┌──────────────────┐
         ▼                           │  approval_events │
┌──────────────────┐                 └──────────────────┘
│  file_snapshots  │
└──────────────────┘
```

---

## 2. Table Definitions & Schemas

### A. `sessions`
Represents an active or historical user session initiated via the Dashboard or Ambient HUD.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | VARCHAR(64) | PRIMARY KEY | Unique session identifier (`sess_...`). |
| `surface` | VARCHAR(32) | NOT NULL | Originating client (`dashboard` or `ambient`). |
| `title` | VARCHAR(255) | NULL | Auto-generated or user-assigned session title. |
| `os_context` | JSONB / TEXT | DEFAULT '{}' | Snapshot of active app, cwd, window at session start. |
| `created_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Session inception timestamp. |
| `updated_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Last activity timestamp. |

### B. `task_dags` & `dag_nodes`
Stores Directed Acyclic Graph plans generated by the Planning Agent.

#### `task_dags`
| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | VARCHAR(64) | PRIMARY KEY | Unique DAG identifier (`dag_...`). |
| `session_id` | VARCHAR(64) | REFERENCES sessions(id) | Associated session. |
| `goal` | TEXT | NOT NULL | Natural language intent of the plan. |
| `status` | VARCHAR(32) | NOT NULL | `pending`, `executing`, `completed`, `failed`, `cancelled`. |
| `created_at` | TIMESTAMP WITH TIME ZONE | NOT NULL | Plan synthesis timestamp. |
| `completed_at` | TIMESTAMP WITH TIME ZONE | NULL | Completion or termination timestamp. |

#### `dag_nodes`
| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | VARCHAR(64) | PRIMARY KEY | Unique step identifier (`step_...`). |
| `dag_id` | VARCHAR(64) | REFERENCES task_dags(id) ON DELETE CASCADE | Parent DAG. |
| `name` | VARCHAR(255) | NOT NULL | Step title / intent. |
| `agent_name` | VARCHAR(64) | NOT NULL | Assigned agent (e.g., `CodingAgent`, `SystemOperatorAgent`). |
| `tool_name` | VARCHAR(64) | NULL | Designated tool (if known ahead of time). |
| `input_payload` | JSONB / TEXT | NULL | Input parameters prepared for the tool/agent. |
| `dependencies` | JSONB / TEXT | NOT NULL, DEFAULT '[]' | List of predecessor node IDs that must succeed first. |
| `status` | VARCHAR(32) | NOT NULL | Execution state. |
| `result_payload`| JSONB / TEXT | NULL | Captured output observations. |
| `error_message` | TEXT | NULL | Failure context if step failed. |

### C. `audit_logs`
Immutable, append-only security ledger.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | VARCHAR(64) | PRIMARY KEY | Unique audit event identifier (`evt_...`). |
| `session_id` | VARCHAR(64) | REFERENCES sessions(id) | Originating session. |
| `step_id` | VARCHAR(64) | NULL | Associated DAG node ID if part of a plan. |
| `agent_name` | VARCHAR(64) | NOT NULL | Agent responsible for requesting the action. |
| `tool_name` | VARCHAR(64) | NOT NULL | Tool requested (`filesystem.modify`, etc.). |
| `action_type` | VARCHAR(32) | NOT NULL | `READ`, `WRITE`, `MODIFY`, `DELETE`, `EXECUTE`, `EXTERNAL_ACTION`. |
| `risk_level` | VARCHAR(32) | NOT NULL | `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`. |
| `inputs` | JSONB / TEXT | NOT NULL | Exact inputs supplied to the tool. |
| `outputs` | JSONB / TEXT | NULL | Captured stdout/result payload. |
| `error` | TEXT | NULL | Any exception, stderr, or non-zero exit code. |
| `policy_verdict`| VARCHAR(32) | NOT NULL | `auto_approved`, `approved_by_user`, `denied_by_user`, `blocked_by_policy`. |
| `approval_id` | VARCHAR(64) | NULL | Reference to approval event if HITL was triggered. |
| `snapshot_id` | VARCHAR(64) | NULL | Reference to file snapshot if mutating operation. |
| `duration_ms` | DOUBLE PRECISION | NOT NULL | Wall-clock execution time. |
| `undone_at` | TIMESTAMP WITH TIME ZONE | NULL | Non-null if this action has been rolled back. |
| `created_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Timestamp recorded by system clock. |

### D. `file_snapshots`
Pre-execution state snapshots enabling atomic rollbacks.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | VARCHAR(64) | PRIMARY KEY | Unique snapshot ID (`snap_...`). |
| `audit_event_id`| VARCHAR(64) | NOT NULL | Associated audit record. |
| `file_path` | TEXT | NOT NULL | Absolute path to target file on host. |
| `sha256_before` | VARCHAR(64) | NOT NULL | SHA-256 checksum prior to execution. |
| `sha256_after` | VARCHAR(64) | NULL | SHA-256 checksum after tool mutation. |
| `backup_storage_path` | TEXT | NOT NULL | Path in `.nexus/snapshots/` where original bytes are stored. |
| `created_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Snapshot capture timestamp. |
| `restored_at` | TIMESTAMP WITH TIME ZONE | NULL | Timestamp of rollback execution. |

### E. `memories`
5-Class memory store supporting provenance tracing and user inspection.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | VARCHAR(64) | PRIMARY KEY | Unique memory item ID (`mem_...`). |
| `memory_class` | VARCHAR(32) | NOT NULL | `working`, `conversational`, `episodic`, `semantic`, `procedural`. |
| `title` | VARCHAR(255) | NOT NULL | Concise summary of the fact or learned pattern. |
| `content` | TEXT | NOT NULL | Full textual content or JSON recipe. |
| `source_session_id` | VARCHAR(64) | NULL | Session where memory was acquired. |
| `confidence` | DOUBLE PRECISION | NOT NULL, DEFAULT 1.0 | Extraction confidence score (0.0 to 1.0). |
| `enabled` | BOOLEAN | NOT NULL, DEFAULT TRUE | User toggle to activate or deactivate memory item. |
| `tags` | JSONB / TEXT | DEFAULT '[]' | Categorization tags. |
| `created_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Creation timestamp. |
| `updated_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Last update timestamp. |

### F. `session_grants`
Dynamic cache of permissions approved by the user during the active session.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | VARCHAR(64) | PRIMARY KEY | Unique grant identifier. |
| `session_id` | VARCHAR(64) | REFERENCES sessions(id) | Scoped session. |
| `tool_name` | VARCHAR(64) | NOT NULL | Tool granted (or `*`). |
| `pattern` | TEXT | NOT NULL | Path or argument regex allowed (e.g., `/Users/apple/coding/nexus/*`). |
| `granted_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Time of grant. |
| `expires_at` | TIMESTAMP WITH TIME ZONE | NOT NULL | Automatic grant expiration timestamp. |
